# 📖 Installation Guide - Studio AI\n\n## Prerequisites\n\n- **Node.js 18+** - Download from nodejs.org\n- **Python 3.9+** - For AI models\n- **GPU (NVIDIA recommended)** - 8GB+ VRAM\n- **Storage** - 50GB+ free space\n- **RAM** - 16GB+ recommended\n\n## Step-by-Step Installation\n\n### 1. Clone Repository\n\n```bash\ngit clone https://github.com/hima-kh/studio-ai.git\ncd studio-ai\n```\n\n### 2. Run Setup Script\n\n```bash\nchmod +x setup.sh\n./setup.sh\n```\n\nThis will:\n- Install Node.js dependencies\n- Create React frontend\n- Create necessary directories\n- Generate `.env` file\n\n### 3. Configure Environment\n\nEdit `.env` file:\n\n```bash\nnano .env\n```\n\nConfigure your GPU:\n\n```\nUSE_GPU=true\nGPU_DEVICE_ID=0\nGPU_MEMORY_FRACTION=0.8\n```\n\n### 4. Install AI Models\n\n**Install Python dependencies:**\n\n```bash\npip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118\npip install diffusers transformers accelerate omegaconf einops\n```\n\n**Download models:**\n\n```bash\n# Open-Sora\nmkdir -p models/open-sora\ncd models/open-sora\n# Download from Hugging Face\ncd ../..\n\n# Stable Video Diffusion\nmkdir -p models/stable-video\ncd models/stable-video\n# Download from Hugging Face\ncd ../..\n\n# Real-ESRGAN\nmkdir -p models/real-esrgan\ncd models/real-esrgan\npip install realesrgan\ncd ../..\n```\n\n### 5. Start Development Server\n\n```bash\nnpm run dev\n```\n\nThis will start:\n- **Backend**: http://localhost:5000\n- **Frontend**: http://localhost:3000\n\n## Troubleshooting\n\n### GPU Not Detected\n\n```bash\n# Check CUDA installation\nnvcc --version\n\n# Check GPU\nnvidia-smi\n\n# Reinstall PyTorch with CUDA\npip uninstall torch\npip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118\n```\n\n### Out of Memory\n\nReduce `GPU_MEMORY_FRACTION` in `.env`:\n\n```\nGPU_MEMORY_FRACTION=0.5\n```\n\nOr use CPU (slower):\n\n```\nUSE_GPU=false\n```\n\n### Slow Generation\n\n- Start with lower quality (720p)\n- Reduce duration (5-10 seconds)\n- Use smaller models\n\n### Port Already in Use\n\n```bash\n# Change port in .env\nPORT=5001\n```\n\n## Docker Installation (Alternative)\n\n```bash\ndocker build -t studio-ai .\ndocker run -p 5000:5000 -p 3000:3000 --gpus all studio-ai\n```\n\n## Next Steps\n\n1. ✅ Installation complete\n2. 📖 Read [Settings Guide](./SETTINGS.md)\n3. 🚀 Start generating!\n"
