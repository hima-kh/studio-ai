multipart/form-data\n\nBody:\n- image: File (JPEG, PNG)\n- prompt: String (optional animation description)\n- settings: JSON {\n    model: 'stable-video' | 'open-sora' | 'flux-video'\n    quality: '720p' | '1080p' | '1440p' | '2160p'\n    fps: 12-60\n    duration: 1-30\n    style: 'cinematic' | 'realistic' | 'artistic' | 'anime' | 'cartoon'\n  }\n\nResponse:\n{\n  \"success\": true,\n  \"jobId\": \"uuid\",\n  \"videoUrl\": \"/outputs/uuid.mp4\",\n  \"status\": \"processing\"\n}\n```\n\n#### Text to Video\n```\nPOST /video/text-to-video\n\nContent-Type: application/json\n\nBody:\n{\n  \"prompt\": \"A cinematic video of...\",\n  \"settings\": {\n    \"model\": \"stable-video\",\n    \"quality\": \"1080p\",\n    \"fps\": 24,\n    \"duration\": 10,\n    \"style\": \"cinematic\"\n
